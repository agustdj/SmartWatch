## Installation

### Clone repository

```bash
git clone https://github.com/agustdj/SmartWatch.git

cd SmartWatch
```

### Backend

```bash
cd backend

npm install

npm run start
```

Create `.env`

```env
PORT=3000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
NODE_ENV=development
```

---

### Frontend

```bash
cd frontend

npm install

npm run start
```

Create `.env`

```env
API_URL=your_api_url
```
